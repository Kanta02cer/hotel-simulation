# slides — 霞ヶ関キャピタル フォーマット準拠プレゼン資料

Lunest 産後ケアホテルの事業性を、霞ヶ関キャピタル（KC）の資料フォーマットに忠実に合わせて
まとめた**社内上長向け**プレゼン資料（PowerPoint）と、その生成一式。

## 成果物

- **`Lunest_事業性評価_KC.pptx`** … 全20枚のデッキ（16:9）。表紙／目次／章扉／本文／Appendix。

## フォーマットの根拠

- **`KC_BRAND_FORMAT.md`** … 公開IR資料と公式ロゴを解析して抽出したKCの資料フォーマット仕様
  （カラー・ロゴ・タイポ・レイアウト規約）。今後の資料もこれに合わせれば体裁を統一できる。
- **`assets/kc_mark.png`** … KCシンボルマーク（公式ロゴの三角形ジオメトリを再構成。文字部分は非複製）。

## 数値の出所

数値は本リポジトリの事業シミュレーター（`src/calc.js`）の**基準ケース既定値**に基づく試算。

- `calc.mjs` … `src/calc.js` のコピー（ESM実行用）。
- `compute_figures.mjs` … 既定パラメータで月次P&L・Y1推移・シナリオ・稼働別オーナー報酬を算出。
  実行：`node compute_figures.mjs`

### 主要な検証結果（基準ケース）
- 当社（KC）オーナー報酬：稼働80%で **¥4,320,000/月（年 ¥51,840,000）**、FAV LUX通常ADR比 **+約87%**。
- オペレーター損益：安定月でも GOP ¥3,040,631 < オーナー報酬 ¥4,320,000 → **営業赤字 ▲¥1,279,369/月**。
- **損益分岐稼働率 86.8%**（目標60%を大きく超過）／ Y1累計 **▲¥18,346,266**（運転資金¥7.0百万円では不足）。
- → 当社収入は魅力的だが、現行条件ではオペレーター採算が成立せず、収入の持続性にリスク。
  報酬体系のハイブリッド化等、条件再設計を前提に付議することを提案。

## 再生成の手順

```bash
cd slides
npm install pptxgenjs sharp        # 生成に必要
node generate_deck.mjs             # Lunest_事業性評価_KC.pptx を出力
# 画像化してQAする場合（LibreOffice + poppler が必要）
soffice --headless --convert-to pdf Lunest_事業性評価_KC.pptx
pdftoppm -jpeg -r 110 Lunest_事業性評価_KC.pdf slide
```

## 注意

本資料は社内検討用の試算であり、投資判断・勧誘を目的とするものではない。
数値は前提条件の変動により変化する。ロゴ・ブランド要素は社内利用を前提とした再現である。
