# NLCS神戸 学生寮STO ― KC参画 社内稟議資料

六甲山に開校予定の国際ボーディングスクール「NLCS神戸（North London Collegiate School Kobe）」の
学生寮・関連施設を対象とした **STO（Security Token Offering）** に、霞ヶ関キャピタル（KC）が
参画することの社内稟議を通すためのプレゼン資料（KCフォーマット準拠・全21枚）。

## 成果物

- **`NLCS神戸STO_KC参画稟議.pptx`** … 稟議デッキ（16:9）。表紙／目次／各章（章扉＋本文）／Appendix。

## この資料の位置付け

- **投資実行の決裁ではなく**、KCが「アレンジャー／スキーム検討支援」として参画し、
  次段階の検討（STO事業者ヒアリング・外部専門家相談）を進めることの承認を求める稟議。
- 投資・貸付の実行判断は、CF・担保・補助金制約・STO販売可否が明確化した後に別途付議する構成。

## 構成（章立て）

## 注意（重要）

- **「日本初」表現は使用しない**（学生用不動産STOの先行事例あり）。「国内先進事例」等に統一。
- STOは公募前提のため、保護者・富裕層への個別販売には別スキームの検討が必要（要ヒアリング確認）。
- 案件規模・利回り等は初期情報に基づく仮置き。本資料は社内稟議・検討用であり投資勧誘を目的としない。
- 対外開示時は案件名（NLCS神戸）の開示可否を八光エルアール側へ事前確認すること。
